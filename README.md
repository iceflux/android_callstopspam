# Call stop spam


## Описание

Приложение для Android API(16) 4.1.2.  
Сбрасывает входящие зонки с неизвестных номеров, т.е. номеров которые не записаны в телефонной книге.  
Режим антиспама можно выключать по необходимости.  
Включает/выключает режим полета по расписанию.  
  
**телефонные номера в телефонной книге должны иметь формат +7 123 456-78-90*  

[Скачать APK](https://gitlab.com/5w/callstopspam/-/blob/main/apk-release/CallStopSpam.apk)
